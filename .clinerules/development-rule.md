# Development Rules

## Konteks Aplikasi
- saya ingin membuat aplikasi personal untuk berbagai kebutuhan saya, misal melihat jadwal kampus, to-do list, jadwal gym, ingin menulis novel, ingin menulis artikel, ingin showcase kemampuan programming, ingin mencoba library, inign mengumpulkan resource untuk belajar, ingin melihat hasil kreasi, ingin melihat statistik channel youtube dan lainnya. Aplikasinya serbaguna.

## Aturan Pengembangan Aplikasi
- full-stack backend frontend dalam 1 repository
- Selalu perhatikan security dalam setiap implementasi
- Selalu jalankan `npm run build` di akhir development
- Selalu jalankan `npm lint` untuk cek penulisan kode
- selalu tunggu terminal selesai npm lint dan run build jangan di close dan asumsikan masalah selesai
- Jangan selesaikan perbaikan jika lint dan build masih ada yang error
- Selalu tulis .md baru di `public/docs` apa saja yang telah dikerjakan
- Selalu gunakan mcp context7 jika berhubungan dengan tools external (library, dokumentasi youtube api dst)
- Selalu gunakan sequential thinking untuk debugging
- Selalu usahakan gunakan template component yang ada daripada build komponent dari awal (misal shadcn, gsap, framer-motion, animejs, reactbits)
